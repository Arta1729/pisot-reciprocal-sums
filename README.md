# verify_pisot.py

This repository contains the code for the paper **"Effective Bounds for Reciprocal Sums of Higher-Order Linear Recurrences"** by Artatrana Suna and Prasanta Kumar Ray. 

It reproduces Tables 1–3 from the paper and the numerical checks discussed in Sections 5 and 6.

## Requirements

You need Python 3.9 or newer. Install the required packages with:

```bash
pip install -r requirements.txt
